Ethical Hacking Mini-Project: Reconnaissance & Attack Surface Assessment

Overview

This project involved reconnaissance and attack surface assessment in an isolated virtual lab using Kali Linux and Metasploitable 2.

Tools Used

Nmap — port scanning, service enumeration and Operating system Fingerprinting

curl and a web browser — web-service inspection

Key Findings

The assessment identified exposed TCP services, potentially vulnerable service versions, plaintext Telnet exposure, and outdated web applications.

Lab Environment

VirtualBox with Kali Linux and Metasploitable 2, operating within an isolated lab environment.
